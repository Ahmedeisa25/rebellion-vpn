Features

Built for quick switches

Everything you need to move your browser to another location, without digging through server lists.

Fastest server

Tests a shortlist of available servers and connects to the one with the lowest latency — handy when you just want a quick location.

Random server

Picks a random location and automatically tries another server if the first one doesn't respond.

530 locations

Browse 50 countries by country, city, or server name. Star favorites and jump back to recent locations.

Exit IP & location

See the exit IP and location after you connect. It is displayed locally in the popup.

Refresh Server List

Update the server list whenever a location is missing or a server stops responding.

WebRTC leak protection

Stops WebRTC traffic from bypassing your VPN while the extension is connected.

Auto-connect on startup

Reconnects to your selected server when Chrome starts — off until you turn it on.

How it works

Three steps, one popup

  1. 01

    Start your VPN

    Connect the compatible VPN service you already use. Rebellion VPN works with that active connection.

  2. 02

    Pick a location

    Open the extension, choose a country or city, then tap the power button. Or let Fastest server choose for you.

  3. 03

    Switch anytime

    Change locations whenever you like. If a server isn't working, refresh the server list and try again.

What you need

Clear about what it does

Rebellion VPN is a browser extension, not a VPN service provider. It changes where Chrome connects through your VPN; it does not provide or build the tunnel.

FAQ

Questions, answered

Does Rebellion VPN include a VPN service?

No. Rebellion VPN is a browser extension that switches the browser's location for a compatible VPN connection you already have. It never creates the VPN tunnel.

Which VPN service does it work with?

A compatible service with an active connection. Available locations depend on that service, and some servers may be unavailable at any given time.

Does it track me or collect analytics?

No analytics, no telemetry, and no data sold. Your settings, favorites, and recent locations stay in Chrome's local extension storage. See the privacy policy.

Why do some servers fail to connect?

Server availability changes. Use Random server to retry automatically, choose another location, or run Refresh Server List to fetch an updated list.

Do I need an account?

No account is created for Rebellion VPN. You only need your existing VPN connection.

How do I remove it?

Open chrome://extensions, find Rebellion VPN, and choose Remove. Removing the extension clears its local settings.
