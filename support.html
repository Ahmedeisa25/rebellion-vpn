Quick start

Rebellion VPN switches your browser's location. It works with a compatible VPN connection that you start separately — it does not create the tunnel.

  1. Start your VPN.

    Connect the VPN service you already use and wait until it reports connected.

  2. Open Rebellion VPN and choose a location.

    Tap the extension icon, open Locations, then pick a country, city, or server. Or use Fastest server to test a shortlist and connect to the quickest one.

  3. Tap the power button.

    The status changes to Connected and the exit IP and location appear once the connection is active.

  4. Change location whenever you want.

    Pick another location and reconnect. If a server isn't working, run Refresh Server List and try again.

Heads up

The first connection can take a little longer while your VPN finishes starting. If the popup shows Not connected, confirm your VPN is running before retrying.

Before you connect

  • An active, compatible VPN connection on the same computer.
  • Chrome 110 or newer.
  • A server list from your VPN service. Available locations and servers depend on that service.

Rebellion VPN is a browser extension, not a VPN service provider. If your VPN subscription is inactive or the service is down, the extension cannot connect.

Server list

The extension loads a server list so it can show locations and available servers. If the list is empty, outdated, or a city is missing:

  1. Open Settings (the gear icon).
  2. Select Refresh Server List.
  3. Wait for the update to finish, then reopen Locations.

Fastest server

Tests a few servers and connects to the lowest-latency one. Results are cached for 15 minutes. Use it when you don't care which city you land in.

Random server

Picks a random location and automatically tries another server if the first one doesn't respond. Good for a quick switch when one server is down.

Troubleshooting

The extension won't connect

  • Confirm your VPN service is connected and working in its own app.
  • Reload the extension from chrome://extensions, then try again.
  • Try a different location — the selected server may be unavailable.
  • Restart Chrome if the connection state looks stuck.

A server isn't working

  • Choose another city or server from the same country.
  • Use Random server so another server is tried automatically.
  • Run Refresh Server List, then retry.

Locations are missing or the list is empty

  • Run Refresh Server List from Settings.
  • Check that your VPN service is reachable, then refresh again.
  • Some locations may not be included in your VPN plan.

Your router, NAS, or printer won't open

  • Open Settings → Local network and make sure Bypass local network is on. Router ranges such as 192.168.x.x, 10.x.x.x, and 172.16–31.x.x then connect directly.
  • If your device uses a hostname instead of an IP address, add it under Extra bypass rules (one host per line) and select Save rules.
  • Reconnect to the VPN after saving so the new rules are applied.

You only want the VPN for one site

Open Settings → Scope, choose Selected sites, then select Add current site. Only that domain and its subdomains use the VPN; everything else connects directly.

Chrome applies proxy settings to the whole browser profile, not to a single tab. That mode scopes by domain, so other tabs on the same domain are covered, and third-party resources loaded from other domains connect directly.

The location changed but the site still shows my old region

  • Reload the page after connecting — many sites cache location data.
  • Clear the site's cookies if it remembers an old region.
  • Disconnect and reconnect to the location once more.

WebRTC leak protection

Enable Block WebRTC leaks in Settings to stop WebRTC traffic from bypassing your VPN while connected. Changing this setting may require a reconnect to take effect.

Auto-connect on startup

Enable Auto-connect on startup in Settings to reconnect to your selected server when Chrome starts. It is off by default. Your VPN still needs to be running.

Exit IP & location

After connecting, the popup shows the exit IP and exit location reported by your VPN connection. These values are displayed locally and are not sent to us.

If the exit IP stays empty, the connection has not completed. Wait a moment, then reconnect; if it still fails, try another server.

Settings & data

Favorites, recent locations, and preferences are stored locally in Chrome's extension storage. To manage them:

  • Clear recent or Clear favorites in Settings.
  • Remove the extension from chrome://extensions to delete all of its local data.

For details, read the privacy policy.

Report an issue

Still stuck? Open an issue and include the details below. It helps to reproduce the problem quickly.

  • Chrome version, operating system, and Rebellion VPN version (2.0.0).
  • The location you selected and what the status showed.
  • Whether the same location works in your VPN service's own app.
  • Any error text shown in the popup — do not include personal data.

Open a support issue

Issues are handled on GitHub. Never post your VPN credentials, exact IP address, or personal information.
